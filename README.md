# Audio Studio Pro

تطبيق Android لتحرير الصوت البسيط، يتيح اختيار ملف صوتي، ومعاينته، وقصه، وإضافة تدرج الدخول والخروج، ثم حفظه في مجلد Downloads.

## الميزات الحالية
- اختيار ملف صوتي (WAV، MP3، M4A وغيرها).
- قراءة مدة الملف وعرضها.
- تحديد بداية ونهاية المقطع بالمؤشرات.
- معاينة المقطع قبل الحفظ.
- تدرج الدخول (Fade In) وتدرج الخروج (Fade Out).
- حفظ الناتج بصيغة WAV في `Downloads/AudioStudioPro`.
- واجهة داكنة بألوان كحلية وذهبية.

## ملاحظات
- الملفات المقصوصة تُحفظ بصيغة WAV، لذلك حجمها أكبر من MP3.
- النسخة الحالية أولية وتعليمية، والميزات المتقدمة مثل التسجيل متعدد المسارات والمؤثرات الإضافية ما زالت في خارطة الطريق.
